# Number Guessing Game 🎯

A simple Python game where the computer selects a random number between 1 and 100, and the user tries to guess it.

## Features

- Random number generation
- Too High / Too Low hints
- Maximum 5 attempts
- Attempt counter
- Invalid input handling
- Play Again option

## Technologies Used

- Python
- Random module
- While loop
- If-else conditions
- Try-except
- User input

## How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Run:

```bash
python guess.py
